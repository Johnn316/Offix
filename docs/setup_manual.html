Installation

2.1 Install XAMPP

  1. Download XAMPP Go to https://www.apachefriends.org and download the installer for your operating system. Select the version that includes PHP 8.x.
  2. Run the installer Install XAMPP to the default path (C:\xampp on Windows). During installation, ensure MySQL and PHP are checked.
  3. Start services Open the XAMPP Control Panel and click Start next to both Apache and MySQL. Both status indicators should turn green.

2.2 Copy Application Files

  1. Place the application folder Copy the ThomasCRM folder into your web root: 
    # Windows (XAMPP)
C:\xampp\htdocs\ThomasCRM\

# macOS (XAMPP)
/Applications/XAMPP/htdocs/ThomasCRM/

# Linux
/opt/lampp/htdocs/ThomasCRM/
  2. Verify the structure The folder must contain at minimum: public/, app/, routes/, config/, lang/, uploads/.
  3. Check uploads directory permissions The uploads/ folder must be writable by the web server process. On Linux/macOS: 
    chmod -R 775 /opt/lampp/htdocs/ThomasCRM/uploads/
    On Windows, XAMPP handles this automatically.

2.3 Configure Database Credentials

Open the file config/database.php and update the values to match your environment:

// config/database.php
return [
    'host'     => 'localhost',
    'dbname'   => 'thomas_crm',   // must match the DB you create in step 3
    'username' => 'root',
    'password' => '',              // set a password in production
    'charset'  => 'utf8mb4',
];
⚠
Production environments: Always set a strong MySQL password and update this file accordingly. Never use the default root / empty password on a public server.
3

Database Setup

3.1 Create the Database

  1. Open phpMyAdmin Navigate to http://localhost/phpmyadmin in your browser.
  2. Create a new database Click New in the left sidebar. Enter the name thomas_crm and set the collation to utf8mb4_unicode_ci. Click Create.

3.2 Run the Migration Files

The application includes several SQL migration files that must be run in order. Import each one into phpMyAdmin under the thomas_crm database using Import → Choose File, or run them via the MySQL command line.

FileDescriptionRun order
schema.sqlCore tables: contacts, tasks, projects1st
schema_migration_phase2.sqlModule tables: invoices, invoice_items, it_assets, modules2nd
schema_migration_users.sqlUsers table + default admin account3rd
schema_migration_settings.sqlSettings table (key-value pairs, default currencies)4th

3.3 Command-line alternative (Windows)

If you prefer the command line, open PowerShell and run each file in order:

# Run from the ThomasCRM root folder
Get-Content schema.sql | & "C:\xampp\mysql\bin\mysql.exe" -u root thomas_crm
Get-Content schema_migration_phase2.sql | & "C:\xampp\mysql\bin\mysql.exe" -u root thomas_crm
Get-Content schema_migration_users.sql | & "C:\xampp\mysql\bin\mysql.exe" -u root thomas_crm
Get-Content schema_migration_settings.sql | & "C:\xampp\mysql\bin\mysql.exe" -u root thomas_crm
✓
After all migrations are complete, the thomas_crm database should contain these tables: contacts, tasks, projects, invoices, invoice_items, it_assets, modules, users, settings.
4

Starting the Application

Option A — PHP Built-in Server (recommended for local use)

Open PowerShell (Windows) or a terminal (macOS/Linux) and run:

# Windows — PowerShell
Start-Process "C:\xampp\php\php.exe" -ArgumentList "-S localhost:8080 -t C:\xampp\htdocs\ThomasCRM\public"

# macOS / Linux
php -S localhost:8080 -t /opt/lampp/htdocs/ThomasCRM/public

Then open your browser and go to http://localhost:8080.

⚠
The PHP built-in server must be started each time you restart your machine. MySQL must also be running (start it via the XAMPP Control Panel).

Option B — Apache via XAMPP

If you have XAMPP's Apache running, the application is accessible at:

http://localhost/ThomasCRM/public/

No additional command is needed — Apache serves the public/ folder automatically once MySQL is running.

First Login & Initial Configuration

5.1 Default Admin Credentials

A default administrator account is created automatically by the migration. Use these credentials for your first login:

URL http://localhost:8080/login Email admin@thomascrm.com Password admin1234
🔒
Change this password immediately after your first login. Go to the user avatar (top-right) → My Settings → Change Password.

5.2 Initial Setup Checklist

Complete these steps after your first login:

  • Change the default admin password (My Settings → Change Password)
  • Update the admin name and email address (My Settings → Profile Details)
  • Upload a profile photo (My Settings → Change Photo)
  • Set your preferred language — English or Swiss German (My Settings → Language)
  • Configure active currencies (Settings → General Settings → Currencies)
  • Set a default currency for new invoices (Settings → General Settings → Default Currency)
  • Enable optional modules (Settings → Modules) — Invoicing, IT Planning
  • Create additional user accounts if needed (Settings → Users → New User)

5.3 Configure Currencies

Navigate to Settings → General Settings. The currency selector lists 130 international ISO 4217 currencies. Check all currencies your organisation works with. The Default Currency will be pre-selected whenever a new invoice is created.

5.4 Enable Optional Modules

Navigate to Settings → Modules. Click Enable next to any module you want to activate. Enabled modules appear in the left sidebar automatically.

ModuleDescription
InvoicingCreate and manage invoices with line items, tax, and multi-currency support. Print-ready layout included.
IT PlanningTrack IT assets (laptops, servers, phones, etc.) with warranty expiry alerts and assignment tracking.
6

User Management

User management is available to admin role accounts only, under Settings → Users.

Roles

RoleAccess
AdminFull access — all modules, user management, general settings, module settings
ManagerFull access to core modules and optional modules. Cannot manage users or settings.
UserStandard access to all core and enabled modules. Cannot manage users or settings.

Creating a New User

  1. Go to Settings → Users and click New User.
  2. Fill in the form — name, email, password, role, and preferred language.
  3. Save. The new user can log in immediately using the email and password you set.

Profile Settings (per user)

Each user can manage their own settings by clicking their avatar in the top-right corner and selecting My Settings. They can update their name, email, profile photo, preferred language, and change their own password.

ℹ
The interface language (English / Schweizerdeutsch) is set per user and applied automatically on login. It can be changed at any time in My Settings.

Features Overview

📋

Contacts

Manage your full contact database — name, email, phone, company, address, and notes. Import from Google Contacts (CSV or vCard).

✅

Tasks

Create and track tasks with status, priority, and due dates. Link tasks to contacts and projects. Supports recurring tasks (daily, weekly, monthly).

📁

Task Planner

Grouped task view showing Overdue, Today, Upcoming, and Recurring tasks at a glance.

💼

Projects

Track projects with status, start/end dates, linked contact, and notes.

🧾

Invoicing (optional)

Create professional invoices with dynamic line items, tax rate, multi-currency support, and a print-ready layout.

🖥

IT Planning (optional)

Track IT assets with type, serial number, assigned user, location, and warranty expiry. Alerts shown for warranties expiring within 60 days.

Navigation

The left sidebar provides access to all modules. The sidebar collapses on smaller screens via the hamburger menu. Admin-only items (Users, General Settings, Modules) appear at the bottom of the sidebar and are only visible to administrator accounts.

Contact Import (CSV / vCard)

ThomasCRM can import contacts directly from Google Contacts in two formats. Go to Contacts → Import.

Option A — Google CSV Export

  1. Open Google Contacts at contacts.google.com.
  2. Click Export (top-right menu). Select Google CSV as the format.
  3. Download the file and upload it on the Import page.

Option B — vCard Export (.vcf)

  1. Open Google Contacts at contacts.google.com.
  2. Click Export → vCard (for iOS Contacts) format.
  3. Download the .vcf file and upload it on the Import page.

Import Behaviour

SituationResult
Contact email already exists in the systemSkipped (no duplicate created)
Contact has no nameSkipped
Contact imports successfullyCounted in the success summary

After import, a summary message shows how many contacts were imported, skipped as duplicates, or skipped due to missing name.

Imported Fields

Name, email, phone, company, address (line 1, line 2, city, state/canton, ZIP, country), notes.

Troubleshooting

ProblemLikely causeSolution
Blank white page PHP error with display_errors off Enable error display: add ini_set('display_errors', 1); temporarily to public/index.php to see the error message.
Cannot connect to MySQL MySQL service not running Open XAMPP Control Panel and start MySQL. Check credentials in config/database.php.
"Table not found" error Migration files not run Run all four SQL migration files in order (see Section 3).
Redirected to /login repeatedly Session not starting Ensure PHP session support is enabled and no output is sent before session_start(). Check for BOM in PHP files.
Avatar / file uploads not saving uploads/ not writable Check that uploads/avatars/ exists and is writable by the web server user.
404 on all pages except home Wrong server root or server not started Ensure the PHP server is started with -t ThomasCRM/public. The public/ folder must be the document root.
Language not switching Session locale not updating Go to My Settings, change the language, and save. The change is applied on next page load.
Import file not accepted Wrong file extension Only .csv and .vcf files are accepted. Ensure the exported file has the correct extension.

The uploads/ directory is intentionally placed outside the public/ web root. Files stored there cannot be accessed directly by a browser URL. They are served through a secure PHP controller that validates file type and prevents path traversal.
